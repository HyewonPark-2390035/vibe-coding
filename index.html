01 · GitHub 소개

GitHub란 무엇인가

🐙 GitHub

Git 버전 관리 시스템을 기반으로 한 클라우드 코드 호스팅 플랫폼입니다. 개발자들이 코드를 저장하고, 변경 이력을 추적하며, 협업할 수 있는 공간을 제공합니다.

⚡ 핵심 개념

Repository — 프로젝트 폴더
Commit — 변경 사항 저장
Push / Pull — 원격 동기화
Branch — 독립 작업 공간

💡 GitHub Pages 기능을 이용하면 리포지터리에 올린 HTML 파일을 무료 웹사이트로 바로 공개할 수 있습니다. 별도 서버 없이도 누구나 접근 가능한 URL이 생성됩니다.

02 · 리포지터리 생성

GitHub 접속 및 로그인

1

브라우저에서 GitHub 접속

https://github.com 에 접속합니다.

2

로그인

우측 상단 [Sign in] 버튼을 클릭하여 계정으로 로그인합니다. 계정이 없다면 [Sign up]으로 먼저 가입합니다.

3

새 리포지터리 시작

우측 상단 [+] 버튼 → [New repository] 클릭

02 · 리포지터리 생성

리포지터리 옵션 설정

1

이름 입력

Repository name에 vibe-coding 입력 (팀 전원 동일한 이름 사용)

2

공개 범위 선택

Public으로 설정 — GitHub Pages 퍼블리시에 필요합니다.

3

README 초기화

Initialize this repository with a README 체크 → [Create repository] 클릭

💡 이름은 영문 소문자, 숫자, 하이픈(-)만 사용하는 것을 권장합니다.

03 · 파일 생성 · 업로드

기본 파일 업로드 방법

🌐 웹에서 직접 만들기

1

[Add file] → [Create new file]

2

파일명 입력 (예: index.html)

3

내용 작성 → [Commit changes]

📁 로컬 파일 업로드

1

[Add file] → [Upload files]

2

파일 선택 또는 드래그 앤 드롭

3

커밋 메시지 입력 → [Commit changes]

💡 Pages가 정상 표시되려면 루트 경로에 반드시 index.html 파일이 있어야 합니다.

04 · Git 설치 · 설정

Git 설치 및 초기 설정

1

Git 다운로드

https://git-scm.com 에서 운영체제(Windows / macOS)에 맞는 버전을 다운로드하여 설치합니다.

2

사용자 정보 설정

터미널(또는 Git Bash)을 열고 아래 명령어를 실행합니다.

# 이름 설정 git config --global user.name "박혜원" # 이메일 설정 git config --global user.email "dreamphw10@ewhain.net"

05 · 클론 · 커밋 · 푸시

리포지터리 클론

GitHub 리포지터리를 내 컴퓨터로 복사하는 작업입니다.

1

HTTPS 주소 복사

리포지터리 페이지에서 [Code] 버튼 → HTTPS 탭의 주소를 복사합니다.

2

클론 실행

터미널에서 원하는 폴더로 이동한 후 아래 명령어를 실행합니다.

git clone https://github.com/HyewonPark-2390035/vibe-coding.git # 클론된 폴더로 이동 cd vibe-coding

05 · 클론 · 커밋 · 푸시

커밋 · 푸시

파일을 수정한 후 변경 사항을 GitHub에 반영하는 과정입니다.

# 1. 변경 파일 스테이징 (모든 파일) git add . # 2. 커밋 (변경 이력 저장) git commit -m "파일 수정: index.html 내용 업데이트" # 3. 원격 저장소에 반영 git push origin main
💡 git add . 은 현재 폴더의 모든 변경 파일을 추가합니다. 특정 파일만 올리려면 git add 파일명 을 사용하세요.

06 · GitHub Pages

GitHub Pages 퍼블리시

1

Settings 이동

리포지터리 페이지 상단 탭에서 [Settings] 클릭

2

Pages 메뉴 선택

좌측 메뉴에서 [Pages] 클릭

3

Source 설정

브랜치 main, 폴더 / (root) 선택 → [Save]

4

URL 확인

약 1~3분 후 배포 URL이 상단에 표시됩니다. https://[username].github.io/[repo-name]/

07 · 팀 협업

팀 협업 리포지터리

📋 생성 방법

1

팀원 중 한 명이 대표로 리포지터리 생성

2

이름: vibe-coding-team

3

Settings → Collaborators → 팀원 전원 초대

🔄 협업 워크플로우

1. 팀 리포지터리 클론
2. 각자 파일 작업
3. git pull → 최신 상태 유지
4. git add → commit → push
5. 팀 Pages에 자동 반영

⚠️ push 전 반드시 pull을 먼저 해서 충돌을 방지하세요.
